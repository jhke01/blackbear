# DefectDynamicsGridAction

!syntax description /DefectDynamics/Grid/DefectDynamicsGridAction

## Description

The `DefectDynamicsGridAction` is a MOOSE action that describes the shared grouped-tail layout
used by every species in the enclosing `DefectDynamics` block. This is invoked using the `Grid`
sub-block within [DefectDynamics](syntax/DefectDynamics/index.md). See that page for a
description, example usage, and parameters.
